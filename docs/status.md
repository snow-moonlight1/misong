# 支持情况与验证状态

适用于 v0.1.0。网盘验收由开发者在 2026-10 使用自有账号和程序生成的测试文件完成；
网盘网页随时可能改版，下表只说明当时验证过的范围，不保证持续可用。

## 2026-10-22 功能复核

- 会话复用已补充平台域名跳转的本地浏览器回归：按实际登录来源保存及恢复，排除其他域名、协议和端口。

- 桌面端新增可配置产物目录；本地模拟回归覆盖打包、发布、上传的目录路由、重启恢复、保留历史任务和运行中拒绝切换。

- README 全新克隆安装、CLI 帮助和格式列表通过。
- 52 项离线 CLI 矩阵中 51 项通过；`trunc` 有损截断无法完整往返，现明确拒绝解码残缺链接。
  覆盖 13 种层格式的文件/目录、加密文件名与 ZIP AES、中文/空格/长文件名、伪装、JSON 门面视频与分卷、
  无清单还原、错误密码、缺卷/坏卷/交换卷内容、公开 SHA-256 校验、merge/raw、文案编码和中转模板。
- 另验证 299 字符路径还原一致；约 2GB 随机源按默认 1900MB 分成两卷并还原，SHA-256 一致。
  该大文件只完成本地发布准备，未上传。
- 本轮 >4GB 脚本复核：7z 与 ZIP64 门面视频均保持测试视频全部 20 帧一致，7za 解出 SHA-256 一致；
  未新增 WinRAR 验证。此前长视频与 WinRAR 的验证记录见下文。
- 桌面预览脚本在浅色/深色下各生成 33 个模拟页面截图，无控制台错误，覆盖向导、模板、密码确认及空间不足提示。

- 初次 CUA Driver 后台启动受 Windows 前台锁限制；所有者手动打开后，原生账号页与链接编解码页已可操作，
  中文和 emoji 兽曰往返一致，夸克及飞猫登录检测通过；真实窗口已完成四步配置、层编辑、模板复用和产物目录选择。

  同夜续测见下一节。下方旧验收表保留，并已补上本轮新结论。

## 打包与离线验证

- Windows 检查点写入已覆盖真实读取句柄的短暂锁定恢复，以及持续拒绝访问时保留旧记录的回归。

- CLI 百度 365 天选项已验证能写入本地待发布计划；不代表本轮完成该期限的真实上传分享。

- 无清单还原在密码链结束后保留原始普通文件，避免误解其中偶然出现的归档及反复复制大文件。

- 兽曰 web / sdk / pojie 及自定义字符集：中文、emoji、扩展汉字和长文本往返验证通过。

- 接收方仅持有分卷与公开 `.sha256` 时，合卷读取校验文件；缺尾卷、篡改或交换卷内容会被拒绝。
  未提供校验信息或显式禁用校验时，CLI 不再显示“通过校验”。

- 大于 4GB 的仅存储 7z 与 ZIP64 归档嵌入门面视频：ffmpeg framemd5 与原视频 1606 帧完全一致；
  7-Zip 26.04 `7za` 与 WinRAR 命令行解出的文件 SHA-256 一致。
- 7z / ZIP 的 `.001` 分卷可由 7za 与 WinRAR 直接解出字节一致的源文件。
- 魔曰兼容性（内置 V3.0.11，对比新版 3.5.5，各 300 组随机样本）：

| 方向 | 结果 |
|---|---|
| 本工具加密 → 新版魔曰解密（文言、传统） | 全部成功 |
| 新版魔曰传统模式 → 本工具解密 | 全部成功 |
| 新版魔曰文言模式 → 本工具解密 | 约 56–67% 成功；失败时报错并提示改用官方网页，不会输出错误内容 |
