适用于 v0.1.0。网盘验收由开发者在 2026-10 使用自有账号和程序生成的测试文件完成；
网盘网页随时可能改版，下表只说明当时验证过的范围，不保证持续可用。

所有六个网盘均已实现网页自动上传与分享，统一的有效期/提取码选项见
[使用指南](user-guide.md#多盘选择与统一分享设置)。

| 网盘 | 已真实验收 | 尚未验收 / 已知限制 |
|---|---|---|
| 夸克 | 5 个文件自动上传、目录分享、三版文案；逐个下载 SHA-256 一致，合卷解密还原一致 | 网页不支持多文件批量下载，需逐个下载 |
| 飞猫 | 作为第一跳：guide.txt / guide.7z 上传与公开分享，下载字节一致；错误密码被拒绝；重开与无头模式复用会话 | 作为本体盘的多文件目录分享未真实验收；“取件码”不是访问密码 |
| UC、迅雷 | 同一任务各 5 个文件上传、7 天带提取码目录分享，合并文案逐一解码一致 | 分卷逐一下载与字节还原未验收 |
| 123 | 同上；另在新版桌面应用中完成一条龙发布（百度第一跳 + 123 本体门面视频），门面视频在线预览已手动复验 | 分卷逐一下载与字节还原未验收 |

新版桌面应用的真实上传目前在百度、123 验收，其他四个网盘通过 CLI 验收。
各账号的单文件大小上限未做边界测试；默认 1900MB 分卷只是保守配置。

## 打包与离线验证

- 接收方仅持有分卷与公开 `.sha256` 时，合卷读取校验文件；缺尾卷、篡改或交换卷内容会被拒绝。
  未提供校验信息或显式禁用校验时，CLI 不再显示“通过校验”。

- 大于 4GB 的仅存储 7z 与 ZIP64 归档嵌入门面视频：ffmpeg framemd5 与原视频 1606 帧完全一致；
  7-Zip 26.04 `7za` 与 WinRAR 命令行解出的文件 SHA-256 一致。
- 7z / ZIP 的 `.001` 分卷可由 7za 与 WinRAR 直接解出字节一致的源文件。
- 魔曰兼容性（内置 V3.0.11，对比新版 3.5.5，各 300 组随机样本）：

| 方向 | 结果 |
|---|---|
| 本工具加密 → 新版魔曰解密（文言、传统） | 全部成功 |
| 新版魔曰传统模式 → 本工具解密 | 全部成功 |
| 新版魔曰文言模式 → 本工具解密 | 约 56–67% 成功；失败时报错并提示改用官方网页，不会输出错误内容 |
