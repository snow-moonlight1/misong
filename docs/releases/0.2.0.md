## 真实网站与账号边界

官网正常界面实测使用 FFmpeg 自制短视频、虚构链接与测试密码。2026-10-30 首批六例有四例通过，两例分别遇到网络和组件下载错误；保留失败记录。后续裸链接/兽曰的有无密码四例全部通过，连同首批魔曰有无密码的通过结果，三个载荷类型的两个密码路径均至少一次完成：生成→保存文件独立读取→新接收上下文读取→`.tkey` 最终原文一致。还覆盖错密码拒绝及模拟网络中断后仅还原重试，不访问或上传真实资源。脱敏报告留在 `tmp/framewords-smoke/`。

这不等于任意网页版本、平台转码或所有浏览器已通过。视频仍依赖官网、浏览器及组件下载，网站故障会明确失败，不静默交付未验证视频。

只读六盘现场检查在并发浏览器负载下、15 秒预算内均返回 timeout，未修改认证快照或误记为账号过期；单盘 45 秒复验夸克得到 logged_in。随后由独立验收会话完成六盘真实只读矩阵，报告见[六盘验收](../dev/v020-live-sixdisks.md)：发现夸克未登录超时、123 登录子域误判、百度未登录骨架冲突、百度自检 1 秒超时及遮挡分类不清共 5 项问题。2026-10-31 已全部修复并复验：飞猫、夸克、UC、123、百度返回 logged_in，迅雷现有凭据真实过期返回 logged_out；隔离空状态下，夸克、123、百度均返回 logged_out；批量 `account check --all` 与单盘一致。自检中夸克、飞猫、UC、百度为 incomplete（入口通过，分享依赖选中文件），123 的真实 splash 浮层标注为 `covered_overlay`，百度不再出现 selector_error。迅雷已登录态及选择器自检需所有者扫码后补验，其他五盘真实自然过期态暂无样本；不宣称完整双状态矩阵已全部实测通过。CLI/API/发布预检使用 45 秒预算（包含浏览器启动）；登录和验证仍由所有者完成。
