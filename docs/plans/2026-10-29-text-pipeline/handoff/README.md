# 帧语兼容的净室交接约定

备用，未排期。当前主线是官网 RPA，此目录及交接材料不是 v0.2 的执行依赖；仅在用户以后明确启动自主兼容研究时使用。

当前状态：只有交接约定；尚无行为规范、官方向量或兼容结果。这里不是已经通过验收的协议说明。

本目录接收行为研究侧新产生、可追溯至允许来源的材料。实现侧只使用下列交接文件及其明确引用的自制样本，不接收完整研究聊天、网站源文件、客户端或原实现分析笔记。

## 必需交付

| 文件（由行为侧生成） | 内容 |
|---|---|
| `spec.md` | 目标版本/模式；外部行为、媒体条件、数据格式、提取/嵌入与密码/纠错所需规范；每条事实关联证据 ID；事实、推断、未知分开 |
| `vectors.json` | 合成测试输入与预期结果、样本 ID/哈希、参数、来源、角色与文件定位；包含官方生成的正例、负例和独立留出样本 |
| `provenance.json` | 证据 ID、来源种类、公开说明 URL 或黑盒实验 ID、日期、操作摘要、可复验方法；不含原实现代码来源 |
| `open-questions.md` | 未知点、已排除假设、冲突证据、下一项区分实验；阻止兼容的缺口明确列出 |
| `compatibility-matrix.md` | 每个版本/模式/密码路径分别标未测、失败或通过；官方→自主、自主→官方、断网和钥匙四类验证分列 |
| `review.json` | `status` 为 `incomplete` 或 `ready_for_implementation`；规范/向量/来源文件哈希、覆盖范围、关键未知项、来源检查结果；不是法律认证或第三方审计证明 |

`ready_for_implementation` 仅表示规范足以开始实现，不表示已互通。仍有关键格式/密码/同步/纠错字段未知，或缺少官方生成样本时，必须是 `incomplete`。审查不能用作者自己的“已完成”替代证据。

## 媒体与证据存放

- 只使用自制或明确有权用于此实验的合成媒体、虚构链接和测试专用文字。不得读取用户真实分享或会话。
- 原始视频、截图、页面记录放在独立实验目录，例如 `tmp/framewords-blackbox/`；它与既有第三方源码研究目录隔离，不能递归扫描整个 tmp。向量使用逻辑 fixture ID、文件名和 SHA-256，单独标记实验目录，不把机器绝对路径写进可提交的规范。
- 原始输出是黑盒实验的数据证据，不是原程序代码；须记录输入视频和生成输出的哈希、当时模式/版本。允许实现侧读取明确列入 vectors 的样本，禁止借样本目录夹带脚本/WASM/安装包。
- 已审核的少量合成 fixture 或生成/变换配方可以进入本项目测试；截图、HTML、真实分享、`.mskey`/`.tkey` 及第三方运行文件不提交。测试专用密码可作为明确标记的合成向量输入，绝不使用真实密码。
- 保存未来回归所需的固定版本向量；不能只引用一个可能失效的官网 URL。生成算法存在随机性时，明确哪些字段应保持，哪些只能按行为/载荷核验，不要求两次输出文件逐字节相同。

## 双向交叉验证反馈

实现侧输出候选文件清单与期望载荷摘要；行为侧只操作正常官方产品检验这些候选，不读取实现侧源码，回传样本 ID、候选 SHA-256、目标版本/模式、实际恢复文本摘要及精确比较结果。失败要附不含私密内容的现象记录。

实现侧用 `questions-for-behavior.md` 提出缺失字段及最小区分实验，行为侧更新交接包。默认由用户转交文件或启动后续对话；本约定不自动授权向其他聊天或外部作者发消息。

“官方输入样本→自主读取”与“自主生成→官方读取”必须分别有证据；自主实现自身往返不能替代交叉验证。平台转码和 B 站取流属于后续项目，不混入本轮完成声明。
